The repository currently contains a single file — `SUMMARY.md` — which describes a full-stack TV tracking web application. The app lets users search for TV shows via the TVMaze API, add them to a personal watchlist, and check off individual episodes or bulk-mark entire seasons as watched. It was built with Bun as the runtime, SQLite for persistence, and a vanilla JS single-page frontend; the UI includes a responsive card grid, collapsible season accordions in a slide-in detail panel, a rewatch mode with separate episode checkboxes, a light theme with DM Sans typography, and filter tabs for All / Watching / Plan to Watch / Completed.
